# 🌌 PixelShifter
A versatile Python-based toolkit designed for advanced image manipulation, automated background removal, and digital steganography. This project is part of my ongoing development in Python automation and security tools.

## 🚀 Features
* **BG-Remover:** Instant AI-powered background removal for various image formats.
* **LSB-Stego (Coming Soon):** Hiding encrypted data within the Least Significant Bits of an image.
* **Privacy Guard (Coming Soon):** Automatic stripping of EXIF metadata to ensure digital privacy.

## 🖼️ Tool 1: Image Background Remover
This utility utilizes AI models to precisely isolate the subject and remove the background. It is ideal for creating transparent assets or preparing images for web development.

### How to Execute:
1. Place your source image in the project directory.
2. Run the script:
    ```bash
    python bg_remover.py
    

```

3. Enter the input file path (e.g., `i.jpg`) and your desired output name (e.g., `itachi.png`).
