
# 🌌 PixelShifter
A versatile Python-based toolkit designed for advanced image manipulation, automated background removal, and digital steganography. This project is part of my ongoing development in Python automation and security tools.

## 🚀 Features
*   **BG-Remover:** Instant AI-powered background removal for various image formats.
*   **LSB-Stego (Coming Soon):** Hiding encrypted data within the Least Significant Bits of an image.
*   **Privacy Guard (Coming Soon):** Automatic stripping of EXIF metadata to ensure digital privacy.

---

## 🛠️ Installation & Setup

Follow these steps to set up the toolkit on your local machine:

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/prajapatiHardik2008/PixelShifter.git](https://github.com/prajapatiHardik2008/PixelShifter.git)
    cd PixelShifter
    ```

2.  **Install Necessary Libraries:**
    This tool requires the `withoutbg` library to process the images.
    ```bash
    pip install withoutbg
    ```

---

## 🖼️ Tool 1: Image Background Remover
This utility utilizes AI models to precisely isolate the subject and remove the background. It is ideal for creating transparent assets or preparing images for web development.

### How to Execute:
1.  Place your source image in the project directory.
2.  Run the script:
    ```bash
    python bg_remover.py
    ```
3.  Enter the input file path (e.g., `i.jpg`) and your desired output name (e.g., `result.png`).

## 🛠️ Installation & Setup

Follow these steps to set up the toolkit on your local machine:

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/prajapatiHardik2008/PixelShifter.git](https://github.com/prajapatiHardik2008/PixelShifter.git)
    cd PixelShifter
    ```

2.  **Install Necessary Libraries:**
    This tool requires the `withoutbg` library to process the images.
    ```bash
    pip install withoutbg
    ```

## 🖼️ Tool 1: Image Background Remover
This utility utilizes AI models to precisely isolate the subject and remove the background. It is ideal for creating transparent assets or preparing images for web development.

### How to Execute:
1.  Place your source image in the project directory.
2.  Run the script:
    ```bash
    python bg_remover.py
    ```
3.  Enter the input file path (e.g., `i.jpg`) and your desired output name (e.g., `result.png`).

### Performance Example:
Using the iconic **Itachi Uchiha** as a test case, the tool effectively isolates the subject from the complex background.

| Original Input (`i.jpg`) | Processed Output (`itachi.jpg`) |
| :--- | :--- |
| ![Original](https://api.gemini.google.com/v1/files/i.jpg) | ![Processed](https://api.gemini.google.com/v1/files/itachi.jpg) |

> **Pro Tip:** Always save the output with a `.png` extension to preserve the transparency layer created by the background removal process.
